# ElderAlert_project
The project is about building an AI-powered safety system for elderly people.
It uses a camera and a microphone to monitor them continuously. If the system detects that the elder is in pain, fear, or distress (through facial expressions) or if it hears screaming or unusual sounds, it will immediately call for help.
This can prevent accidents from becoming life-threatening by making sure family or caregivers are alerted in time.
